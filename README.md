# Diwali Sales Analysis – Power BI Dashboard

## 📌 Project Overview

This project presents an interactive **Diwali Sales Analysis Dashboard** developed using **Microsoft Power BI**. The dashboard analyzes sales performance, customer purchasing behavior, product categories, and demographic trends to identify key business insights and patterns.

The goal of this project is to transform raw sales data into meaningful visual insights that can support **data-driven business decisions**.

---

## 🛠️ Tools & Technologies

* **Power BI Desktop**
* **Power Query** – Data cleaning and transformation
* **DAX** – Measures and calculated columns
* **Data Visualization**
* **Data Analysis**

---

The dashboard provides insights into:

## 🧹 Data Preparation

The dataset was prepared using **Power Query** before creating the dashboard.

The data preparation process included:

1. Removing unnecessary columns
2. Handling missing values
3. Removing duplicate records
4. Correcting data types
5. Renaming columns where required
6. Creating appropriate calculated fields
7. Preparing the data for visualization
